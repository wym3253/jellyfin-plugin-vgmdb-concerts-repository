# VGMdb Concerts Plugin Repository

This public repository contains only the Jellyfin catalog manifest and compiled release packages.

Stable historical packages and their versioned URLs remain available for rollback. Each version retains its original Jellyfin ABI and package checksum.

Add this URL under **Jellyfin Dashboard → Plugins → Repositories**:
